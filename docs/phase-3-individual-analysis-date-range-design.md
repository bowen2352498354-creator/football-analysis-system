# 第三阶段：个人总体分析时间范围设计

## 交互目标

让教练在不改变教练看板全局筛选条件的前提下，为当前学生单独指定 LLM 总体分析的起止日期。

## 交互规则

1. 在“LLM 个人总体分析”卡片中提供开始日期、结束日期以及“全部时间”“最近30天”快捷按钮。
2. 起止日期均为包含边界，即开始日和结束日当天的记录都纳入分析。
3. 日期变更后，旧报告标记失效并回到待生成状态，避免旧报告被误认为新范围结果。
4. 开始日期晚于结束日期时即时提示并禁用生成按钮。
5. 选定范围内没有A级科研有效记录时禁用生成，并明确显示范围内记录数与A级样本数。

## 数据一致性

- 前端先过滤以提供即时数量反馈；请求同时发送 `dateFrom` 和 `dateTo`。
- 后端对逐次数据重新执行日期过滤，再执行A级科研门控。
- 报告同时返回：`requestedPeriod`（教师选择范围）和 `period`（实际有效数据覆盖范围）。
- 代表性骨骼定格、五维均值、错误发生率、自查任务和 LLM 文本必须使用同一批范围内A级数据。
- 报告指纹包含学生、起止日期与有效记录集合，保证不同分析范围的自查任务互不串用。
