# 第四阶段：班级 LLM 报告一键打印设计

## 1. 阶段目标

教练在全局控制台选定“学校 + 班级”，可继续叠加实验组别与日期区间，然后一键生成可直接打印的 Word 文档。打印版与屏幕上的个人总体分析共用同一份 A 级科研有效证据、同一 LLM 结构和同一自查任务，避免出现两套口径。

## 2. 教练端交互

- 顶部操作区增加“班级一键打印”。只有选择了具体学校、具体班级且当前筛选存在记录时才可用。
- 按钮左侧提供 `A4 2 人/页` 与 `A4 3 人/页` 两档密度；默认 2 人/页，适合阅读，3 人/页用于节约纸张。
- 生成范围继承当前全局筛选：学校、班级、实验组、开始日期、结束日期。
- 生成期间按钮显示加载状态并阻止重复提交；完成后浏览器直接下载 `.docx`。
- 完成提示展示实际生成学生数；没有 A 级科研有效数据的学生会被跳过并显示数量。

## 3. Word 版式

- 纸张：A4 纵向，窄页边距，页眉标注学校、班级与分析时段。
- 每名学生是一张不可跨页的独立卡片，外框使用虚线作为裁剪辅助线。
- 2 人/页：保留更完整的 AIGC 文本，适合作为常规发放版本。
- 3 人/页：压缩字号与摘要字数，保留全部信息模块，适合节约纸张版本。
- 卡片信息顺序：
  1. 学生编号、学校、班级；
  2. 分析时段、均分、最近成绩、变化值、A 级有效次数；
  3. 击球瞬间骨骼定格图与五维能力整体画像；
  4. AIGC 总体结论、进步分析、优势、盲区、训练处方与剂量；
  5. 专属图式自查任务、三次纸面打卡框与教练签字栏。

## 4. 数据与接口

`POST /api/coach/class-print-report`

请求字段：

- `school`：具体学校；
- `classGroup`：具体班级；
- `group`：可选实验组；
- `dateFrom` / `dateTo`：可选闭区间；
- `studentsPerPage`：只允许 2 或 3。

处理流程：

1. 从未软删除的全局训练档案中按请求范围筛选；
2. 按学生分组，只纳入 `qualityGrade=A` 且 `researchEligible=true` 的正式尝试；
3. 复用个人总体分析构建函数生成结构化报告；
4. 读取代表性尝试的受控关键帧资产，缺失时打印明确占位图；
5. 生成 A4 Word 并以附件形式返回；
6. 响应头返回成功学生数与跳过学生数，供前端反馈。

## 5. 边界与失败处理

- 未选择学校或班级：前端禁用，后端继续强校验。
- 日期格式错误或起止颠倒：返回 400/422，不生成文件。
- 范围内无学生：返回 404。
- 有学生但均无 A 级科研有效尝试：返回 422，并说明原因。
- 单次最多 120 名学生，避免意外选取超大范围导致长时间阻塞。
- LLM 不可用时沿用现有确定性兜底报告，保证班级文件仍可生成。
- 关键帧缺失或损坏时仅使用占位图，不影响其他学生及整份文档。

## 6. 验收标准

- 2 人/页与 3 人/页均严格按指定密度分页，最后一页允许不足额。
- 学生卡片不跨页，骨骼图与五维图不拉伸、不重叠、不裁切。
- 报告文字、日期范围、A 级有效次数与屏幕版一致。
- Word 可由 Microsoft Word/LibreOffice 打开并直接打印为 A4。
- 每名学生卡片底部均有专属自查任务、3 个打卡框和签字栏。
- 生成失败不会返回伪装成 Word 的 JSON 文件。
