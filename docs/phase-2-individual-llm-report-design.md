# 第二阶段：LLM 个人总体分析报告设计

## 目标

把当前只有“优势 / 盲区”两段文字的个人总体分析，升级为可阅读、可审计、可复用到后续 Word 打印阶段的完整报告。

## 报告信息架构

1. 报告抬头：学生编号、分析起止日期、A级有效样本数、排除记录数、生成时间。
2. 关键摘要：平均分、最近分、首末变化量和样本质量说明。
3. 视觉证据：选取分析范围内最近一次A级有效尝试作为代表性击球瞬间骨骼定格图，并明确标注日期和分数。
4. 五维整体画像：对分析范围内A级有效尝试的五维分数分别求均值，不使用非正式样本。
5. AIGC 分析处方：总体评价、纵向变化、稳定优势、习惯性盲区、训练处方和建议剂量六个固定字段。
6. 证据摘要：展示高频错误及发生率，确保教师可以核对模型结论来源。
7. 专属图式自查：按总体最低维度生成任务，三次打卡与教练确认状态持久化；同一批证据重复生成时复用原任务。

## 数据约束

- 后端重新执行A级科研门控，前端统计只用于交互提示。
- 五维画像、分数变化和错误发生率均由确定性代码计算，LLM 只负责文字组织。
- 代表性定格图通过受控图片接口返回，不暴露服务器文件路径。
- 总体自查任务以本次有效尝试集合的摘要指纹作为持久化键。
- 第二阶段使用当前看板筛选内记录；自定义起止日期由第三阶段接入同一报告契约。

## 后续打印兼容

报告响应采用固定结构化字段，第四阶段可直接将同一响应渲染到 Word 卡片，无需重新调用 LLM。
